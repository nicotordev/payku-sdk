# Support

Thanks for using `@nicotordev/payku`.

## How to get help

| Need | Where |
|------|--------|
| Bug report | [Open a bug issue](https://github.com/nicotordev/payku-sdk/issues/new?template=bug_report.yml) |
| Feature idea | [Open a feature request](https://github.com/nicotordev/payku-sdk/issues/new?template=feature_request.yml) |
| Questions / usage | [GitHub Discussions](https://github.com/nicotordev/payku-sdk/discussions) |
| Security vulnerability | See [SECURITY.md](./SECURITY.md) — do not open a public issue |
| Payku API / account | [Payku Help Center](https://ayuda.payku.com) · [Payku Docs](https://docs.payku.com/) |

## Before opening an issue

1. Search existing [issues](https://github.com/nicotordev/payku-sdk/issues) and [discussions](https://github.com/nicotordev/payku-sdk/discussions)
2. Confirm you are on the latest published version
3. Sanitize logs — never paste `PAYKU_PUBLIC_TOKEN` or `PAYKU_PRIVATE_TOKEN`

## Response expectations

This is a community-maintained open-source project. Maintainers review issues and PRs as capacity allows. Clear reproduction steps speed things up a lot.
