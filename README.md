# payku-sdk

SDK en TypeScript para integrar [Payku](https://payku.com/about), la pasarela de pagos LATAM, en aplicaciones web.

Payku facilita transacciones digitales para empresas y emprendedores desde 2017, con soporte en Chile, Perú y el resto de LATAM.

## Características

- Tipado completo en TypeScript
- Runtime recomendado: [Bun](https://bun.com)
- Orientado a e-commerce, suscripciones, payouts y links de pago

## Instalación

```bash
bun add @nicotordev/payku
```

o con npm:

```bash
npm install @nicotordev/payku
```

## Desarrollo

```bash
bun install
bun run build
bun test
```
